#84 业务分析 中等

没有 A/B 时，怎么评估一次大促或运营活动的增量效果？前后对比为什么会骗人？

增量效果反事实DID选择偏差需求透支

🎯 考察意图

考察候选人会不会把「活动周比上周高」当成活动效果。要讲清增量=事实−反事实、前后差混进趋势季节和同期动作、以及没有随机时怎么构造对照（未开放城市 DID、合成对照、预注册未中）。只会说「环比看看」、把参与用户 vs 未参与当对照、或只报活动周 GMV 不看透支，这题就浅了。

📐 回答框架

  1. 先定义增量：要的是相对「假如没办这场活动」的差，不是相对上周、也不是相对去年。
  2. 拆开朴素前后差：里面叠了趋势、季节/日历、同期投放与库存、以及谁选择来参与。
  3. 找对照：未触达、未开放城市、预注册未中、合成对照；说清识别假设。
  4. 识别纪律：平行趋势、无溢出、无预期；处理组按「被分配/被覆盖」而不是「实际核销」。
  5. 收口：点估计 + 假设 + 护栏（透支、渠道挤出、售后）；没有对照就只报描述，不说增量。

💬 参考答案（口述版）

一句话：活动增量是「办了」相对「假如没办」的差，缺的那一截叫反事实。上周、去年、没参与的人，都不是自动的反事实。没有随机实验时，评估的全部工作就是：把反事实造得尽量像，并讲清哪条假设一破估偏会往哪边走。

为什么前后对比会骗人。 记活动期指标为 Y_1，活动前窗口为 Y_0。Y_1 − Y_0 里至少叠了四样东西：① 本来就在涨或跌的趋势；② 星期几、发薪日、年货节、天气；③ 同期别的动作（品牌广告、竞对降价、库存补货、推荐改版）；④ 活动本身。你把 ①②③ 全记在这场大促头上，增量就被污染。同比 Y_今年活动 − Y_去年活动 同样脏：去年力度、流量结构、供给约束都变了，减出来的是「两年活动周之差」，不是今年这场的增量。

更脏的一种对照：参与 vs 未参与。 来核销的人更活跃、更价格敏感、本来就会买。拿他们和没领券的人比，组间差里一大块是选择，不是券。这和实验里的触发偏倚是同一类错：处理组被定义成「实际吃到处理的人」，对照是「自己没来的人」。

正确开口：增量 = Y(办了) − Y(没办)。 你永远看不到同一个人的 Y(没办)。能做的是找一群「没被这套活动覆盖、但本来会跟处理组走同一条趋势」的人/城/天，用他们的变化去代理反事实。

没有 A/B 时，对照从哪来（按干净程度）。
1. 地理/门店开关 + DID。 活动只在部分城市或门店上，其余当对照。双重差分：

lift ≈ (Y_处理,后 − Y_处理,前) − (Y_对照,后 − Y_对照,前)

第一项是处理组自己的前后差，第二项用对照的前后差把共同趋势减掉。识别假设是平行趋势：假如不上活动，两组的变化会一样。活动前多画几期，趋势平行才敢用；只看活动前一周对齐不够。
2. 合成对照。 没有干净的单城对照时，用若干未开放城市的加权组合去拟合处理组活动前的曲线，再用这个合成序列外推活动期。权重要在活动前锁死，不能拿活动期拟合优度去调。适合「全国大促但有少数未上线城/渠道」。
3. 预注册 / 资格未中。 有报名或资格门槛时，未中签、候补、刚好卡在门槛外的人，比「完全没听说」更像处理组。断点附近（门槛左右一小段）比全样本匹配干净。
4. 时间序列 / 预测反事实。 全国同时上、一个对照都没有时，用活动前的季节模型预测活动期，残差当「异常」。这是最弱的：任何同期冲击都会进残差。只能当描述和报警，汇报时要写「这是相对模型预测的偏离，不是因果增量」。

口述例子：周末满减，大盘 GMV 比上周 +18%。拆开：这周本来就有发薪日和一次品牌投放，对照城市（没满减、投放预算相当）同期 +11%。DID 剩 +7pp，这才接近满减增量。再把窗口拉到活动结束后 7 天，处理城比对照城低了 3pp——有一部分是把下周需求提前了。业务会上你要两行都报：活动周 +7pp，含前后 14 天净增量只有 +4pp。只报 +18% 是在邀功，不是评估。

三条识别纪律，说不清就不要报因果。
1. 平行趋势。 活动前处理/对照的差分应当平稳。不平就分层（城市等级、新老）或换合成对照，不要硬 DID。
2. 无溢出。 对照城用户别被全国广告、社交传播带起来；供给别从对照城调去处理城。溢出一旦发生，对照被污染，DID 低估（和 SUTVA 那题同一方向）。
3. 无预期 / 无提前抢跑。 预热期已经把货垫进购物车，活动「开始日」切晚了，增量会被切到窗外或看起来更冲。处理组按覆盖名单（城、渠道、资格）做 ITT，不要事后改成「核销用户」。

护栏：透支、挤出、售后。 大促常把下个月的单提前，也常把自然流量挤进活动渠道（last-click 看起来活动很猛，增量其实是归因搬家）。评估窗口至少覆盖：活动前基线、活动期、活动后回落期。净增量 ≈ 活动期超额 − 前后窗口的透支。同时看退款、客诉、毛利，GMV 增量可以是亏钱换来的。

收尾：面试官要听的是「增量相对反事实 → 前后差和参与 vs 未参与都不是反事实 → DID/合成对照/资格未中，并报平行趋势、溢出、透支」。能主动说没有对照就只描述不说增量，这题就过了。

💭 面试官可能的追问

追问 1：DID 的平行趋势怎么检查？不平的时候还能报吗？

活动前至少画 4～8 个同长度的期，看处理−对照的差分是否在 0 附近晃、有没有已经分开的斜坡。能量化就做活动前假处理：把开始日往前挪，估计应接近 0。不平先问是水平不同还是斜率不同：水平不同 DID 仍可用（差分会消掉），斜率不同则反事实会继续分叉，估偏。处理：按城市等级/新老分层各自 DID；或改合成对照去拟合活动前曲线；或加入活动前趋势协变量。不平还硬报，要在结论里写成「假设不成立时的敏感区间」，不能只给一个点估计。

追问 2：全国同时上线、一个对照城市都没有，还能评估吗？

因果增量变得很弱，不要装成实验。还能做的三档：① 若有预注册/会员档/渠道白名单，用未覆盖人群或门槛外用户当对照，声明选择仍然在；② 用活动前季节模型做预测反事实，残差当异常，明确这是「相对预测的偏离」；③ 看活动后回落：若活动后相对活动前明显更低，至少能描述透支，不能把活动周毛增量当净增量。全国大促更应在设计阶段留 holdout：一个渠道、一个城市集群、或一小撮用户不进活动，评估才有落点。已经全上了，就只报描述 + 假设，决策用「值不值得再办」的区间，不要用一个精确 ROI 去结案。

追问 3：活动把下个月需求提前了，GMV 增量怎么报才不骗业务？

把窗口写成三段：基线、活动期、活动后（至少覆盖一个完整购买周期，电商常用活动后 7～14 天，耐用商品更长）。净增量 = 活动期相对对照的超额 − 活动后相对对照的亏损（透支） − 若有预热抢跑再减预热超额。渠道挤出另报一行：活动渠道 GMV 起来、自然渠道掉下去，last-click 会把搬家算进活动。会上三行：活动周毛增量、净增量（含前后）、毛利/退款护栏。业务只想听「+18%」时，你要主动把净增量和护栏放在同一页，否则评估在帮运营申预算，不是在量效果。

⚠️ 常见踩坑

  • 把活动周减上周、或今年活动周减去年活动周，直接叫增量
  • 用实际核销/参与用户 vs 未参与用户当对照，把选择偏差当成券效
  • DID 不查平行趋势，或对照城已被全国广告和调拨运力污染仍当干净对照
  • 只报活动周 GMV，不看活动后回落和渠道挤出，把透支和归因搬家当增长
  • 全国同时上线还报精确 ROI，把时间序列残差说成因果
  • 处理组事后改成「核销成功用户」，把 ITT 变成触发偏倚

🧠 记忆锚点

增量是相对「假如没办」不是相对上周；前后差只是描述，没有对照就没有因果增量。
