#65 业务分析 中等

核心指标突然跌了，你怎么做波动归因和贡献度拆解？

波动归因贡献度拆解乘积指标结构效应水平效应

🎯 考察意图

考察候选人会不会先排除「假跌」（口径、埋点、日历、对账），再用可加总的贡献度把跌幅拆到因子和切片，而不是凭感觉点几个维度。只说「分层看看」、说不清乘积指标怎么拆、拆完加总对不上本期差额，这题就浅了。

📐 回答框架

  1. 先验真：口径有没有改、埋点/任务是否异常、窗口是否对齐、是否工作日/大促/故障。
  2. 再写恒等式：把指标拆成可乘或可加的因子（如 GMV=UV×转化×客单），声明基期与本期。
  3. 贡献度：链式拆解让各因子贡献加总等于总差额；切片再拆结构效应与水平效应。
  4. 收口：按贡献大小排序，形成可验证假设，落到动作或实验，而不是停在一张表。

💬 参考答案（口述版）

一句话：先确认跌是真的，再把指标写成恒等式，用「链式贡献」把总差额拆干净，最后按贡献最大的因子和切片去验证假设。

第一步不是拆，是验真。 我会先问四件事：① 指标说明书有没有改（成功态、去重键、是否含退款）；② 上游任务、埋点、分区是否延迟或空跑；③ 窗口是否完整（别拿今天 10 点对昨天全天）；④ 日历：工作日、大促退潮、竞对活动。对账过不了，先修数据，不讲故事。

第二步写死公式。 电商常用 GMV = UV × 支付转化 × 客单价；内容常用 有效时长 = DAU × 人均次数 × 次均时长。基期、本期、成功态写在标题上。没有恒等式，贡献度无法加总。

第三步链式拆解，保证加总得回总差额。 以 GMV 为例，基期下标 0、本期 1：

ΔGMV = (UV1-UV0)×转化0×客单0
      + UV1×(转化1-转化0)×客单0
      + UV1×转化1×(客单1-客单0)

三项分别是流量贡献、转化贡献、客单贡献，加起来等于 GMV1-GMV0，没有残差。不要三项都乘基期——那会留下交叉项，面试时说不清「为什么对不上」。

第四步切片：结构 vs 水平。 渠道/类目/新老客上，总变化 = 结构效应 + 水平效应。结构：(本期占比-基期占比)×基期水平，讲的是「流量是不是挪到了更差的渠道」；水平：本期占比×(本期水平-基期水平)，讲的是「同一渠道自己掉了」。两套加总也应对上总差额。

口述例子：GMV 周环比少 800 万。验真通过后链式拆：UV 贡献 -100 万、转化 -600 万、客单 -100 万。转化里新客渠道占比升高（结构 -200 万），老客转化自己掉（水平 -400 万）。假设落到支付失败率和某券到期，用漏斗单步和实验护栏去验证，而不是再开一张十维透视。

收尾：面试官要听的是「验真 → 恒等式 → 可加总贡献 → 按大小行动」。能主动说链式拆法消掉交叉项，这题就过了。

💭 面试官可能的追问

追问 1：为什么三项都用基期相乘会对不上？交叉项怎么处理？

若 Δa×b0×c0 + a0×Δb×c0 + a0×b0×Δc，会漏掉 ΔaΔb、ΔaΔc、ΔbΔc 这些交叉项，加总小于真实差额。链式把「已经更新的因子」留给后面的项，交叉项被吸收，三项加总精确等于 Δ。汇报时只报链式三项，不要再单独甩一个「交互贡献」把业务绕晕；若业务一定要看交互，放到附录并声明不可单独优化。

追问 2：结构和水平怎么向业务解释？切片维度选几个？

结构是「人去了更差的地方」，水平是「老地方自己变差了」。例如付费渠道占比升高且该渠道转化低，是结构；App 首页转化自己掉，是水平。维度先用指标树上已有的 2～3 个（渠道、新老、类目），不要一次切十刀，单元格过稀贡献会抖。先看贡献绝对值 Top，再下钻，避免「每个维度都看一眼」。

追问 3：指标是比率（转化率、留存率）不是乘积，还能做贡献度吗？

比率先拆成分子分母的贡献，或按人群做加权：总体转化变化 ≈ 结构（人群占比变化）+ 各组转化变化。不要对比率直接套 GMV 那套三因子链式。留存还要声明队列窗口，不能拿「今日留存」对「昨日留存」却混了不同注册日。比率贡献仍要求加总能对回总变化，对不上就回到加权公式，而不是四舍五入糊过去。

⚠️ 常见踩坑

  • 不验真就归因，把口径变更、任务空跑、残缺窗口讲成业务下跌
  • 乘积指标三项都乘基期，交叉项被吃掉，贡献加总对不上总差额
  • 同时切十个维度，单元格又稀又抖，讲不出主因
  • 停在透视表，没有按贡献大小形成可验证假设和动作

🧠 记忆锚点
