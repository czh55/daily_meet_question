#62 行为面试 中等

介绍一下你所在业务的行业基本面，以及你负责方向的技术基本面。

项目深挖领域基本面行业认知

🎯 考察意图

判断你是否站在上下文里做技术：懂行业如何赚钱与约束，也懂技术选型背后的取舍，避免「工具人」印象。

📐 回答框架

  1. 行业：谁付钱、核心指标、主要约束（合规/供给/季节性）。
  2. 技术：主链路、一致性/时效/成本三角、关键技术债。
  3. 两者交汇：你的工作如何服务行业目标。
  4. 边界：你不装懂的邻域诚实说。

💬 参考答案（口述版）

分两层，各用两三句说透：

行业基本面：这个生意怎么赚钱（广告/交易抽佣/订阅等）、北星或关键经营指标是什么、增长靠拉新还是提频、主要约束是供给、合规、季节还是获客成本。例如电商：「交易与广告是收入盘，看 GMV 还要看毛利与履约；大促是脉冲流量，数据系统必须扛峰值与延迟」。

技术基本面：数据从哪进到哪出、批流如何分工、口径如何统一、质量与成本如何权衡。点明你负责段的关键取舍——例如「我们优先口径一致与可回刷，接受 T+1；实时只做经营监控，不做复杂归因」。

交汇句：我做的 XX（质量/主题域/实验）直接服务 YY 经营决策或风险控制。这样面试官觉得你能在新行业里快速抓基本面，而不是只会某一家的表。

🔍 关键词

赚钱逻辑北星指标约束时效成本一致性取舍

💭 面试官可能的追问

追问 1：如果让你一周了解一个新行业，你怎么做？

先问清谁付钱与北星指标；再画主业务漏斗；然后对照数据主链路与口径争议点；最后列出最大风险（合规/稳定性/成本）。

追问 2：技术基本面里你最熟与最不熟的是什么？

诚实分层：熟的给深度例子；不熟的说学习路径与你如何借助协作补齐，避免全懂人设。

⚠️ 常见踩坑

  • 只背公司介绍 PPT，说不清赚钱逻辑
  • 技术叙述堆名词，没有取舍
  • 行业和技术两张皮，讲不出交汇

🧠 记忆锚点

行业讲清怎么赚钱与约束，技术讲清主链路与取舍，再用一句话把两者接上。
