#51 行式存储和列式存储有什么区别？数仓为什么常用 Parquet？

大数据计算 中等

考察候选人会不会把「列存更快」落成存储布局和查询形态的匹配：分析查询通常只读少列、扫很多行，所以同一列挨在一起才能做列裁剪、编码压缩和谓词下推。只背 Parquet/ORC 名词，却说不清什么查询更快、什么查询更慢、小文件为什么会把优势吃掉，这题就浅了。... [查看完整讲解]
